# ClubPlanner – SV Gemmingen V2

Diese Version bildet jetzt die gewünschte Vereinsplattform als Grundgerüst ab.

## Bereits enthalten
- Dashboard
- Belegungsplan
- Trainings- und Spieltermine manuell eintragen
- Orte Gemmingen und Stebbach
- je Ort Hauptplatz und Trainingsplatz
- je Ort Heimkabine und Gastkabine
- automatische Konflikterkennung bei zeitlicher Überschneidung
- Platzkonflikte
- Kabinenkonflikte
- Excel-Export
- browserbasierte Nutzung

## Als nächster Entwicklungsschritt
1. automatischer Import des aktuellen FUSSBALL.DE-Vereinsspielplans
2. Wochen- und Monatskalender
3. Mannschaftsverwaltung
4. Benutzer und Rollen für Trainer / Jugendleitung / Platzwart / Vorstand
5. Platzsperren und Ferien
6. PDF-Export
7. später Benachrichtigungen / Kalenderanbindung

## Deployment
Wie zuvor über GitHub + Render.
Alle Dateien dieses Ordners in ein GitHub-Repository hochladen und dieses Repository als Render Web Service deployen.
