# ClubPlanner 5.0 – Sprint 4.5.1

## Manuelle Änderungen & PDF-/Druckexport
- Manuell geänderte FUSSBALL.DE-Spiele werden mit `MANUELL` gekennzeichnet.
- Kennzeichnung erscheint in Monatskalender, Wochenplan und Spieleliste.
- Beim nächsten erfolgreichen offiziellen FUSSBALL.DE-Abgleich wird die Kennzeichnung automatisch entfernt und der offizielle Stand übernommen.
- Der überflüssige Button `Aktualisieren` wurde entfernt.
- Neuer Button `PDF / Drucken` im Monatskalender.
- Druckvorlagen: angezeigter Monat, Hinrunde bis 31.12., Rückrunde 01.01.–01.06. und frei wählbarer Zeitraum.
- Ausgabe ist DIN A4 quer; bei mehreren Monaten wird jeder Monat auf einer eigenen Seite ausgegeben.
- Standortfarben, Konflikte und MANUELL-Kennzeichnungen werden in die Druckansicht übernommen.
- Im Browser-Druckdialog kann direkt `Als PDF speichern` gewählt werden.

Alle Funktionen aus Sprint 4.5.0 bleiben erhalten.
